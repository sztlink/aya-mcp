# Security policy

AYA MCP is experimental and does not yet provide an operating-system sandbox.

Do not use the current repository to execute untrusted code or to claim isolation of Blender, TouchDesigner, After Effects or any other application.

To report a vulnerability privately, contact the repository owner through the security reporting channel configured on GitHub. Do not include credentials, private project files or client material in a public issue.

Security claims must name their level:

- contract validation;
- process isolation;
- operating-system enforcement.

A lower level must never be described as a higher one.
